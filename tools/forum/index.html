🖼 Logo 管理
上傳或貼入圖片 URL 後，系統自動去除多餘白邊並置中，格子內大小比例統一，不需個別調整。輸出後電腦版一排五個、手機版一排四個；標題與 Logo 採緊湊扁平排版，勾選「聯名 Logo」會佔用兩格寬。
上線發布建議優先使用 Drupal file URL。本機上傳的 Logo 可能會以 base64 / data:image 輸出，適合臨時預覽或小圖；長期維護請先將 Logo 上傳至 Drupal file / media library，再把最終圖片 URL 貼回工具。

📅 議程 Agenda（選填）
可直接貼上原始議程，大部分情況不需要手動整理：只要每個場次的時間單獨一行（例如 10:15 – 10:55），系統就會自動偵測時間並開始一個新場次；接下來一行是場次名稱，之後每一行是一位講者，格式 姓名 ｜ 職稱 ｜ 公司（可以有好幾位講者，各自一行）。空白行可留可不留，不影響判讀。想插入不屬於任何場次的分節標題（例如「CEO Summit」），該行前面加上 ##（例如 ## CEO Summit: Global Ecosystem Leaderships** 即可（例如 **Panel A: XXX**）。此區塊顯示在 Logo 與報名費用之間；Drupal 後台完整議程功能仍會顯示在頁面最下方，兩者不衝突。
